# Fake News Detector
---

Fake News Detector using Machine Learning. The main goal is to create a system that can classify whether a news article is **fake/hoax** or **real/valid** based on the text content. The project compares the performance of Naive Bayes and SVM.
Based on the result, SVM performs slightly better than Naive Bayes, but both models still have low accuracy. This means the models are not yet strong enough to fully understand the meaning of news text.
